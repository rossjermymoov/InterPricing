Accessorials

UPS accessorial charges. Net = list × (1 − discount). toggle ones apply when ticked on the calculator; auto ones apply automatically from weight & dimensions. DPD £ defaults to 0 (DPD accessorials not loaded). Accessorials are added to the base and fuel applies on top.

Create rate card

Set a global markup to fill every service, then fine-tune any of them below (e.g. a lower margin on air, higher on road).

Markup applies to the base rate and fuel only — duties and per-shipment surcharges are passed through without markup. It drives the on-screen customer prices, the report, and the exported rate card.

Cheapest by country — report

Select destinations below. Uses the weight, dimensions, value, markup and options set above. Run to preview, open a printable report, or export a full customer rate card to Excel. With destinations selected the export is limited to them; with none selected it exports every country.

Build the rate card

Configure the customer-facing card. It shows final prices only — markups, fuel and cost are never included. Uses the destinations selected above (or all if none) and the parcel details from the calculator.

Customer rate cards & links

Save the setup above as a private link for a customer. Each link is unguessable and shows only that customer’s prices — no one can see another customer’s rates, and there is no public list. Links always reflect your latest rates.
